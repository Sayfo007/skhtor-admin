# Skhtor Admin app (+ backend)
Contains: the admin app (`www/index.html`), the Firebase backend (`functions/`, `firestore.rules`) and two workflows:
- **Build Android APK** – builds the admin app.
- **Deploy Firebase backend** – publishes the push-notification functions and the database rules.

See the step-by-step guide in the chat. Secrets needed in this repo: `GOOGLE_SERVICES_JSON`, `FIREBASE_SERVICE_ACCOUNT`.
